# ✦ Shadow ✦ - Gifting & Precision Laser-Cutting Website

Shadow is a modern, playful, neo-brutalist gifting and precision laser-cutting e-commerce web platform. It features custom laser-cutting quote estimation, personalized gift ordering, dynamic product search & category filtering, a shopping cart drawer, interactive product customization preview, and an Admin Management Panel.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite
- **Language**: JavaScript (ES6+)
- **Styling**: Modern Neo-Brutalist Pastel Vanilla CSS (thick rounded borders, crisp box-shadows, soft pastels)
- **Icons**: Lucide React (`lucide-react`)
- **Effects**: Canvas Confetti (`canvas-confetti`)

## 🎨 Design Theme
Inspired by playful, high-precision laser craft:
- Header: Soft Lavender (`#E2D4F8`)
- Body Background: Warm Pastel Cream/Yellow (`#FFFDE7`)
- Accents: Pink (`#FF9EAA`), Pastel Cyan/Blue (`#AEE2FF`), Soft Mint (`#C1E1C1`), Neon Coral
- Neo-Brutalist borders (`3px solid #1a1a1a`), offset box shadows (`4px 4px 0px #1a1a1a`)

## 🛠️ Features
1. **Header & Navigation**: Brand Logo `✦ Shadow ✦`, Search Bar, Live Cart Badge, Admin Mode Switcher.
2. **Hero Banner**: "Precision Cutting, Max Cuteness." tagline & quick action buttons.
3. **Category Sidebar**: Quick filter by Home Décor, Personalized Gifts, Jewelry, Wedding & Events, Stationery, or Laser Crafts.
4. **Interactive Product Grid**:
   - Product cards with price, badges, rating, quick customization trigger, and add-to-cart.
5. **Interactive Laser Cutting Studio (Custom Quote & Studio)**:
   - Select material (Acrylic, Plywood, MDF, Leather, Stainless Sheet).
   - Select material thickness (2mm, 3mm, 5mm, 8mm).
   - Enter custom dimensions (width x height mm) and upload vectors/text.
   - Real-time instant price calculator.
6. **Product Detail & Customization Modal**:
   - Custom engraving text input, font picker, finish selection, and real-time live preview.
7. **Shopping Cart Drawer & Checkout**:
   - Slide-out cart, item count, quantity updater, subtotal calculation, free shipping bar, and instant checkout with confetti celebrate!
8. **Admin Panel Modal / View**:
   - Manage product inventory (add/edit products, stock counts, toggle status).
   - View submitted custom laser cut quote requests.

## 💻 Getting Started

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
